# Contributing to SREESH × MRITHULA Studio

We maintain uncompromising standards for design refinement, type safety, performance, and accessibility.

## Code Standards
- **TypeScript**: Strict mode enabled. No `any` types.
- **Components**: Functional components with clean props interfaces.
- **Accessibility**: All buttons must have accessible names. Form controls must have labels. Colors must meet WCAG 2.1 AA contrast.
- **Git Hygiene**: Conventional commits (`feat:`, `fix:`, `docs:`, `refactor:`).
- **Zero Fabrication**: Never push fabricated achievements, metrics, or personal details.
