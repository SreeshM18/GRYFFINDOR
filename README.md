# SREESH × MRITHULA
> **Two Minds. One Creative Space.**  
> *"Individual minds. Shared ambition."*

A luxury-grade, high-performance digital studio and dual-identity professional platform built for **Sreesh M** & **Mrithula**. Designed with editorial typographic restraint, dark obsidian & burgundy color tokens, responsive mobile-first grids, Web Audio synthesized feedback, and a private authenticated workspace cockpit.

---

## ⚡ Key Highlights & Capabilities

### 1. Dual-Identity Public Platform
- **Equal Prominence Architecture**: Independent portfolios for Sreesh M (`/sreesh`) and Mrithula (`/mrithula`), linked via seamless profile transitions.
- **Cinematic Dual-Hero**: Masked reveals, interactive split cards, and ambient mouse-reactive constellation canvas.
- **Project Showcase & Deep-Dive Case Studies** (`/work`, `/work/[slug]`): Multi-dimensional filtering by owner, discipline, and technology with architectural challenge/solution breakdowns.
- **Collaborations Hub** (`/collaborations`): Collaborative software products, joint hackathons, and synergy matrix.
- **Technical Capabilities Matrix** (`/skills`): Verified proficiencies across AI, systems, UI/UX, and cloud.
- **Interactive Timeline** (`/journey`): Chronological milestone progression across university studies, open-source architectures, and studio milestones.
- **Verified Credentials Gallery** (`/achievements`): Hackathon wins, fellowship awards, and certificate document viewer.
- **ATS Resume Generator** (`/resumes`): Single-click print/PDF styling with clean ATS-compliant markup.
- **Direct & Collaborative Inquiries** (`/contact`): Honeypot spam-protected inquiry system with privacy guarantees.

### 2. Private Collaborative Workspace (`/dashboard/*`)
- **Studio Cockpit Overview** (`/dashboard`): Real-time sprint tasks, project metrics, and technical notes.
- **Kanban Task Pipeline** (`/dashboard/tasks`): Interactive status tracking across Todo, In Progress, Review, and Done.
- **Markdown Knowledge Base** (`/dashboard/notes`): Architectural documentation and research scratchpad.
- **Project Management** (`/dashboard/projects`): Repository linkage, deployment status, and live URLs.
- **Calendar & Milestones** (`/dashboard/calendar`): Release dates, hackathons, and deadlines.
- **Portfolio Headless CMS** (`/dashboard/content`): Live in-browser editing of bios, taglines, and metrics without modifying source code.

## 🛠️ Technology Stack

- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS v3.4
- **Motion & Audio**: Framer Motion, HTML5 Canvas, Web Audio API Synthesizer
- **Backend & Database**: Supabase (PostgreSQL 15 with strict Row Level Security)
- **Icons**: Lucide React & bespoke SVGs
- **Deployment**: Vercel ready with zero configuration

## 🚀 Quick Start / Local Development

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Start the local development server**:
   ```bash
   npm run dev
   ```
   Navigate to `http://localhost:5173`.

3. **Build for production**:
   ```bash
   npm run build
   ```

## 🔒 Security & Database Migration

The production PostgreSQL database schema and strict Row Level Security (RLS) policies are provided in:
👉 `supabase/migrations/20261108000000_init_sreesh_mrithula.sql`

To apply to your Supabase instance:
```bash
supabase db push
```
